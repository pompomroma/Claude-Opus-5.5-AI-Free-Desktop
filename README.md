## FAQ

**Is Claude Opus 5.5 actually free?**
Yes. MIT client, no subscription, no in-app paywall. You do not need Anthropic Pro to run the app.

**Claude Opus 5.5 release date?**
September 22, 2026. Timeline sits in the model panel.

**Fable 5.1 vs Opus 5.5?**
Opus 5.5 for accuracy and code review. Fable 5.1 when you need the long autonomous pass.

**claude opus vs sonnet?**
Sonnet 5 is faster. Opus 5.5 is the flagship reasoner. The picker can auto-fall back.
